To run a co-expression with CEMiTool, you first need to download the IID2 annotation file which contain information about protein-protein interactions (see id2_geneName.txt file)
Then you can run a) coexpression.r with its corresponding functions in b) coexpression_functions.r to:
	a) Get modules and hubs in which a correlated gene expression is found. Input is the filtered file form 1.TCGA_pre-processing
	b) Get an over representation analysis
	c) Plots which show modules and protein interactions
