To produce a principal component analysis and plots

(1) Run make_pca.r with its corresponding functions in pca_functions.r to:
	a) Make a PCA file. The results are saved in a directory called 'PCA*, which is created when running the script
	b) Make summary on the PCA file. It will be saved in a directory called 'summary', which is created when running the script
	c) Make plots pf cumulative summary, variances and PCA, all are saved in a directory called 'plots', which is created when running the script
